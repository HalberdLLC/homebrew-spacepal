# Homebrew tap for Spacepal

[Spacepal](https://getspacepal.com/) is a Mac menu bar app that gives every macOS Space a name and a live preview, and switches between them instantly.

```sh
brew install --cask tankucukhas/spacepal/spacepal
```

Requires macOS 14 or later. The app has a 14-day free trial and then costs $9.99 once ([pricing](https://getspacepal.com/pricing/)). Spacepal updates itself, so `brew upgrade` is only needed for a fresh install.

The app is closed source; this repository only holds the cask. Problems with the app: support@getspacepal.com.
